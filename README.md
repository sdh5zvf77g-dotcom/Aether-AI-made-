# Aether – Lifelong AI Companion (2027 Prototype)

**Your lifelong AI partner for learning, research, health & daily life.**  
Private • On-device first • Built for everyone

## What This Is

A high-fidelity interactive **mobile web prototype** of Aether, designed for the 2027 smartphone market. It demonstrates the core experience of a universal AI life companion that combines:

- Agentic multi-domain assistance
- Personal Knowledge Graph
- Lifelong learning paths
- Intelligent health insights
- Research → action pipelines
- Extreme accessibility & privacy controls

This is a **working demo** (not production native code). All AI responses are simulated with realistic multi-step reasoning to show the intended product behavior.

## How to Run / Test

1. Open `index.html` in any modern mobile browser, or
2. Serve locally:
   ```bash
   cd aether-app
   python3 -m http.server 8080
   ```
   Then visit `http://localhost:8080` on your phone or desktop (use mobile emulation).

### Tested Flows
- Splash → Enter
- Home / Morning Brief with energy, learning progress, priorities
- Agent chat with multi-step prompts (Research+Plan, Health+Schedule, Budget)
- Capture (voice / photo / text / link simulation)
- Research mode with findings, notes, and actions
- Knowledge Graph view + search
- Health insights + energy chart
- Learning paths
- Settings (accessibility toggles, privacy controls, memory ledger)
